# Favourite Cities cover images

Drop a photo in here named after the city on the Favourite Cities sheet, slugified
(lowercase, spaces and punctuation replaced with `-`):

- `London` → `london.jpg`
- `Ibiza Town` → `ibiza-town.jpg`
- `Den Haag` → `den-haag.jpg`

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`.

Any city without a matching file falls back to the initials placeholder, so this
can be filled in gradually — no need to source all of them at once.
