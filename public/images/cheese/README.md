# Favourite Cheese cover images

Drop a photo in here named after the **cheese** on the Favourite Cheese
sheet, slugified (lowercase, spaces and punctuation replaced with `-`):

- `Mature Blue Stilton` → `mature-blue-stilton.jpg`
- `Ford Farm Dorset Red` → `ford-farm-dorset-red.jpg`

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`.

Any cheese without a matching file falls back to the initials placeholder,
so this can be filled in gradually — no need to source all of them at once.
